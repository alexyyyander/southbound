# 局域网扫描报告（脱敏示例）

> 这是公开仓库中的**脱敏示例**。真实扫描结果只保存在本地 `data/SCAN_REPORT.local.md`，不进入仓库。

- **示例网段**：192.168.1.0/24，网关 192.168.1.1
- **方法**：ARP + ICMP sweep + mDNS/SSDP + 关键设备定向端口扫描
- **范围**：仅本机所在二层网段；不尝试登录、口令猜测或漏洞利用

## 示例设备

| 示例设备 | 示例 IP | 开放端口 | 分级 |
|---|---|---|---|
| 主路由/网关 | 192.168.1.1 | 53, 80, 443 | T0 |
| NAS | 192.168.1.20 | 22, 80, 443, 5000 | T2 |
| 打印机 | 192.168.1.30 | 80, 631, 9100 | T0 |
| ESP32 | 192.168.1.40 | 3000 | T1 |
| 编排主机 | 192.168.1.50 | 22, 5000 | T3 |
| 手机/平板 | 192.168.1.60–65 | 无 | T0 |

## 示例结论

- 平坦局域网里，ARP + mDNS + 定向端口扫描足以做设备清点；
- 路由器、NAS、打印机、ESP32 与 Mac 分别覆盖 T0–T3 档位；
- 手机/平板使用随机 MAC，通常没有开放端口，只作为数据源；
- 真实环境中的主机名、MAC、设备型号和端口状态不应公开。

## 扫描盲区

- 多播被屏蔽时，mDNS/SSDP 只能看到本机；
- 休眠设备与不响应 ICMP、且无开放端口的设备会漏掉；
- 大网段的全端口扫描可能被网络策略或权限限制拦截。

## 安全建议（通用）

1. 关闭不需要的 Telnet、FTP、UPnP 和 WAN 侧管理；
2. NAS/路由器/编排主机使用强密码、两步验证和最小权限；
3. 高风险设备（门锁、电源、燃气）走 `AccessHub` 策略 + 人工确认；
4. 扫描与接入只用于自己拥有或获授权的网络。
